# pcybriwsky/tap

Homebrew casks for [Noodle](https://github.com/pcybriwsky/noodle), stretching while Claude is noodling.

```bash
brew install --cask pcybriwsky/tap/noodle
noodle setup
```

`Casks/noodle.rb` is generated from [`packaging/homebrew/noodle.rb`](https://github.com/pcybriwsky/noodle/blob/main/packaging/homebrew/noodle.rb) and updated by Noodle's release workflow, so send changes there.
